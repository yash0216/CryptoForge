# CryptoForge
CryptoForge is a full-stack crypto trading platform featuring real-time market data, secure transactions, and AI chatbot support. Built with React, Redux, Spring Boot, and MySQL, it supports crypto buying/selling, wallet management, and payments via Stripe and Razorpay, with robust authentication including two-factor login and password recovery.

## 📌 Overview

**CryptoForge** is a comprehensive crypto trading platform built with a modern tech stack. It enables users to buy/sell cryptocurrencies, manage portfolios, perform secure wallet transactions, and access real-time market data through Gemini and CoinGecko APIs. An integrated AI chatbot answers crypto-related queries for enhanced user experience.

## 🔐 Features

- 🔒 **Secure Authentication**: Login, Register, 2FA, and Forgot Password functionality using Spring Security.  
- 💬 **AI Chatbot**: Get instant crypto-related answers via Gemini and CoinGecko APIs.  
- 💱 **Buy/Sell Crypto**: Smooth interface for trading multiple cryptocurrencies.  
- 💼 **Portfolio Management**: Monitor and manage crypto holdings with real-time data.  
- 👛 **Advanced Wallet System**:
  - Wallet-to-wallet transfers  
  - Add balance to wallet  
  - Withdraw to bank account  
- 📊 **Transaction History**:
  - View wallet and withdrawal history  
- 🔍 **Search Coin**: Instantly search for any coin and view detailed info.
